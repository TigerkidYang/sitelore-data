title: Search result sorting requires the Go button
applies_when: Signed out, English desktop arXiv search results, Microsoft Edge; verified 2026-10-06.
last_verified: 2026-10-06
status: active
---

Changing the Sort results by dropdown does not immediately reorder the displayed results. The selected option can change while the list still shows the previous order. Click the adjacent Go button, then verify the refreshed result order. This behavior was observed with two different searches in separate browser contexts.
